# SkyMaster ATC

SkyMaster ATC is a standalone ATC client for controlling AI traffic in Lockheed Martin Prepar3D (P3D) and Microsoft Flight Simulator X (FSX) using SimConnect.

## Status
Bootstrapping repository structure and Phase 1 (SimConnect initialization + desktop UI skeleton).

## Prerequisites
- Windows 10/11
- Visual Studio 2022 (recommended) and/or .NET SDK (will be specified once the solution is added)
- SimConnect (FSX/P3D) installed/configured on the machine running the simulator
